# Guitar Physical Model & QA Automation

## Быстрый старт
```powershell
cmake -B build
cmake --build build
.\build\Debug\guitar_synth.exe 440
pytest -v
```

## Суть

Программа синтезирует звук щипка гитарной струны с помощью физического алгоритма **Карплуса — Стронга** (дискретная линия задержки + БИХ-фильтр нижних частот в петле обратной связи) и сохраняет сигнал в бинарный PCM WAV-файл (`44.1 кГц`, `16 бит`).

**Цель проекта:**
- Реализовать математическую модель колебаний гитарной струны на C++17.
- Автоматизировать проверку граничных режимов и спектральных характеристик модели на Python.

**Стек:**
- Ядро модели: `C++17` (`std::deque`, исключения, RAII)
- Сборка: `CMake`
- Автотесты: `Python`, `pytest` (`fixtures`, `conftest.py`, `@parametrize`, `pytest.approx`)
- Цифровая обработка сигналов: `NumPy`, `SciPy` (`rfft`, теорема Винера — Хинчина)

## Автоматизация тестирования (QA)
Набор из **10 автотестов** (`tests/python/test_audio.py`) проверяет:
1. Корректность сборки, запуска CLI-приложения и генерации непустого WAV-файла.
2. **Граничные значения и классы эквивалентности:** защита от неположительных частот (`f <= 0`) и наложения спектров (алиасинга) выше частоты Найквиста (`f >= 22050 Гц`) с проверкой кода возврата и `stderr` (`BUG.md`).
3. **Спектральную верификацию частоты (`110, 220, 440, 880 Гц`):** расчёт основной частоты синтезированного звука через вещественное БПФ (`np.fft.rfft`) и автокорреляцию с проверкой относительного допуска `3.5%`.

# Guitar Physical Model & QA Automation

## Суть

Программа синтезирует звук щипка струны с помощью алгоритма Карплуса-Стронга и сохраняет результат в WAV файл.

**Цель проекта:** 
- Реализовать математическую модель гитарной струны
- Автоматизировать проверку корректности работы модели

**Использовано:**
- Ядро модели: C++
- Сборка: CMake
- Автотесты: Python + pytest
- Анализ звука: NumPy, SciPy

## Автоматизация тестирования (QA)
В проекте реализованы автоматизированные тесты на Python (библиотека `pytest`), которые проверяют:
1. Корректность запуска C++ приложения.
2. Целостность и наличие выходного аудиофайла.
3. (В планах) Анализ спектра звука с помощью преобразования Фурье для верификации частоты.

## Как запустить
1. **Сборка C++:**
   - Откройте проект в VS Code.
   - Используйте расширение CMake для сборки (цель `guitar_synth`).
2. **Запуск тестов:**
   - Создайте окружение: `python -m venv venv`
   - Активируйте и установите зависимости: `pip install pytest numpy scipy`
   - Запустите тесты командой `pytest`
